Financials | Relatório Power BI
Projeto desenvolvido como desafio prático da formação Power BI Analyst da DIO.

O objetivo foi desenvolver um relatório interativo utilizando a base de dados Financials, explorando informações financeiras por meio de gráficos, indicadores e filtros.

O relatório possui duas páginas:
Visão Geral, página 1: apresentação dos principais indicadores e informações financeiras.
Análise Detalhada, página 2: exploração dos dados por meio de diferentes recursos visuais.

Recursos utilizados:
Gráficos e indicadores (KPIs)
Segmentadores de dados
Botões de navegação
Indicadores (Bookmarks)
Visualização de dados

Ferramentas utilizadas:
Power BI Desktop
Power BI Service
GitHub

Base de dados disponibilizada pela instrutora Juliana Zanellatto.
